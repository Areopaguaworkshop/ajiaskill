Answer

Make ajia-learn a host-driven review loop, not a bigger SKILL.md. Auto-install every learned skill only behind an automatic scan, quarantine, backup, ledger, and rollback.

  1. MCP cannot see turns; host plugins and hooks can.
  2. Reuse the foundry as the one managed store.
  3. Match Hermes' safety class: scan, quarantine, backup, rollback, immutable core/user.
  4. Prove the engine on one host, then wire the others.

Can auto-approve be disabled?

Yes. Auto-approve is the automatic install path. It is enabled by default, and every part can be turned off. All keys are under learning.

3

Why can't the MCP server do this alone?

The MCP server only sees ajia_search and ajia_use calls. It never sees the transcript or the end of a turn. The review loop must live in the host.

OpenCode 2.2 exposes the pieces a plugin needs: ctx.session.context reads the transcript, ctx.session.generate runs a transient review on the session model, and ctx.skill.transform can register a learned skill. 1

What happens to a generated skill?

Diagram structure
  • Session ends trigger
  • Review + plan review
  • Scan scan
  • Quarantine quarantine
  • Install install
  • Ledger + rollback ledger
  • install → ledger · record
  • review → scan
  • scan → install · pass
  • scan → quarantine · block or warn
  • trigger → review

The pipeline is ordered. No install happens before a scan, and no failure after backup is silent.

  1. Session ends ↗

    The host plugin takes a transcript snapshot and passes it to the engine.

  2. Scan ↗

    The generated skill runs through the safety scan. Block or warn goes to quarantine.

  3. Install ↗

    Back up the foundry and installed copy first, then atomically copy to ~/.agents/skills/ajia-<slug>.

  4. Ledger ↗

    Before and after hashes are recorded. A failed install restores the backup.

What must be true before auto-install?

Auto-install is the riskiest choice

Because automatic install is enabled by default, the safety path cannot be optional. A missing gate means no install, not a warning.
